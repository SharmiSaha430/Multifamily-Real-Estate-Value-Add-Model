# Riverside Apartments | Multifamily Value-Add Underwriting

**Excel investment model · Real estate acquisitions · 5-year hold**

An Excel-based underwriting model for a **hypothetical 220-unit multifamily acquisition**. The project evaluates acquisition financing, phased renovations, property operations, debt repayment, investor returns, and downside risk.

## Investment snapshot

| Metric | Modeled result |
|---|---:|
| Purchase price | $42.0M |
| Initial debt / sponsor equity | $27.3M / $16.463M |
| Renovation program | 220 units · $3.96M |
| Target rent premium | $225 per renovated unit / month |
| Base-case levered IRR | **28.28%** |
| Equity multiple | **3.29x** |
| Minimum DSCR | 1.83x |
| Year 5 yield on cost | 8.56% |
| Exit cap rate | 5.50% |
| Combined execution downside IRR | **9.49%** |

## Model scope

- **Acquisition:** Assumptions, Sources & Uses, and unit-level Rent Roll.
- **Value-add plan:** Phased renovation schedule and renovation economics.
- **Operations and financing:** Annual operating forecast, NOI, interest-only debt, amortization, DSCR, and debt yield.
- **Investor returns:** Levered/unlevered returns, exit valuation, and an Equity Value Bridge showing the drivers of appreciation.
- **Risk analysis:** A 30-case rent-growth/exit-cap sensitivity table plus a combined Execution Downside scenario.

Start with **`Cover` → `IC Summary`**, then follow the supporting worksheets through `Returns`, `Equity Value Bridge`, `Sensitivity`, and `Execution Downside`. The workbook contains **13 worksheets**.

## Investment conclusion

The base case projects attractive returns, but valuation is sensitive to the assumed exit cap rate. Under combined stress—slower rent growth, lower occupancy, reduced renovation premiums, cost overruns, and a higher exit cap—the levered IRR falls to **9.49%**, below the **10% downside hurdle**. This supports a **REVIEW** recommendation rather than unconditional approval.

> **Disclaimer:** This is a hypothetical portfolio case using illustrative assumptions, not a live transaction, verified appraisal, or investment recommendation. Financial results are model outputs, not forecasts of an actual property.
